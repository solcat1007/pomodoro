# 番茄钟 (Pomodoro Timer) v2.0

简洁但完整的番茄工作法计时器，帮助保持专注、高效工作。单文件 PWA，离线也能用。

## v2.0 更新亮点

- **自定义时长**：专注 / 短休息 / 长休息分钟数、长休息间隔均可设置并本地保存
- **任务关联**：维护任务列表，每个番茄钟可标注当前任务，并显示各任务累计番茄数
- **专注统计**：今日番茄数、本周专注分钟、累计番茄数，附最近 7 天柱状图（localStorage 持久化，保留 60 天）
- **声音提醒**：Web Audio API 实时合成提示音与白噪音，无需任何外部音频文件
- **桌面通知**：阶段结束弹出浏览器通知（首次开始计时时申请权限）
- **深色/浅色主题**：一键切换，主题偏好随设置保存
- **键盘快捷键**：`空格` 开始/暂停，`R` 重置（输入框内不触发）
- **中英文切换**：界面支持中文/英文
- **PWA 离线可用**：Service Worker 缓存页面资源

## 原有功能

- 专注 / 休息自动交替，用目标时间戳计时，后台掉帧也不会走慢
- 开始 / 暂停 / 继续 / 重置，番茄计数与环形进度可视化

## 使用方法

1. 用浏览器打开 `index.html`（或部署为静态站点后添加到主屏幕）
2. 在「时长设置」里按需调整专注、休息时长与长休息间隔，点击保存
3. 在「任务列表」添加任务，点击任务即可设为当前番茄的标注
4. 点击「开始」或按 `空格` 启动；到点自动进入休息并播放提示音、弹出通知
5. 需要环境音时打开「白噪音」；按 `R` 可随时重置
6. 首次开始时会请求通知权限，建议允许以接收时间到提醒

## 技术栈

纯 HTML / CSS / JavaScript 单文件，Web Audio API、Notification API、localStorage、Service Worker，零依赖、零外部资源。

## 彩蛋秘籍

内置 SOLCAT EASTER EGG PROTOCOL v2.0，试试这些隐藏入口：

| 操作 | 效果 |
| --- | --- |
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花，播放胜利旋律 |
| 连点顶部标题 5 次 | 打开隐藏开发者面板 |
| 输入 `solcat` 后按回车 | 切换赛博朋克隐藏主题（再按一次还原） |
| `Ctrl + Shift + T` | 同上，切换赛博朋克隐藏主题 |
| **专属彩蛋**：任务名包含 `solcat` 并添加 | 解锁「SOLCAT 的陪伴」隐藏任务，播放专属旋律 |

打开浏览器控制台还能看到 ASCII 署名与更多提示。已解锁的彩蛋可在开发者面板中查看。
