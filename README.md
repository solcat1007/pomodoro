# 番茄钟 (Pomodoro Timer)

简洁的番茄工作法计时器，帮助保持专注、高效工作。

## 功能

- **专注/休息交替**：默认 25 分钟专注 + 5 分钟休息循环
- **视觉区分**：专注时青色边框，休息时橙色边框
- **开始/暂停**：随时暂停和继续计时
- **重置**：一键回到初始状态
- **番茄计数**：记录已完成的番茄数量
- **桌面通知**：时间到后发送浏览器桌面通知提醒
- **中英文切换**：界面支持中文/英文
- **全屏模式**：专注无干扰

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击"开始"启动 25 分钟专注倒计时
3. 专注结束后自动进入 5 分钟休息
4. 休息结束后自动切换回专注，番茄计数 +1
5. 如需中断，点击"暂停"或"重置"
6. 首次使用会请求通知权限，建议允许以接收时间到提醒

## 技术栈

纯 HTML/CSS/JavaScript，使用 Notification API 发送桌面通知。
